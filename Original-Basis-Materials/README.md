# Original Basis Materials

This folder holds the original Inner Tepenia source files that served as structural templates when building Toronto Fell Out's own equivalent documents throughout `Storyline/`, `Worldspace/`, `Game-Mechanics/`, `Dev-Road-Map/`, `testing/`, and `Press-Outreach/`.

**Why this exists:** the large copy-paste-and-reorganize pass that brought Inner Tepenia's folder structure into this repo was never committed to git, so once those files got rewritten in place with Toronto Fell Out's own content, the original Inner Tepenia versions weren't recoverable from git history. These are fresh copies pulled directly from the Inner Tepenia repo (`/home/kuroskalacs/Documents/Doll-Fi/media/games/Inner Tepenia/InnerTepeniaGDD`) at the same relative paths, so the provenance trail — what a given Toronto Fell Out file was originally adapted from — stays visible without needing to go dig through the sibling project.

**None of this is Toronto Fell Out canon.** Everything in this folder is Inner Tepenia's own content (its cast, its Antarctic/Concordia setting, its MACHINE stat system, its Zodiac districts) kept purely for reference — what did the template look like before adaptation, in case a future pass wants to re-check the original shape or extract something that got missed.

Folder structure mirrors where each file's Toronto Fell Out counterpart lives in the main repo tree (e.g. `Original-Basis-Materials/Worldspace/Design_Principles.md` is the source for `Worldspace/Design_Principles.md`).
