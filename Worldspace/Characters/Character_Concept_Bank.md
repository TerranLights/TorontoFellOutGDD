# Character Concept Bank
## Reusable Archetypes, Factions & Questlines

**Status: empty — pending Toronto Fell Out's own character design.** This file preserves Inner Tepenia's structural format for a specific, useful purpose: a holding pen for archetype/faction/questline concepts that come up during character development but turn out not to fit the specific character they were generated for. Rather than being discarded, they get written up here in full so they can be reassigned to a different future character, NPC, or background faction later.

Toronto Fell Out has no designed characters yet, so there is nothing to reassign — this project currently has zero districts, zero factions, and zero named companions or NPCs. No entries have been invented to fill this file. Populate it organically, the same way Inner Tepenia's version grew: whenever a character concept generated during design doesn't end up matching the character it was written for, write it up here rather than throwing it away.

## Format (for reference — no entries yet)

Each entry should note which character originally prompted the concept and why it was reassigned, followed by whichever of these subsections actually apply:

- **`## From: [Character Name]`** — with an italicized one-line note: *Reassigned because: [reason].*
- **`### Archetype: [Name]`** — a reusable character archetype description, including personality fit and any potential district/faction affiliation.
- **`### Faction: [Name]`** — a reusable faction concept, including philosophy, what they do, size, tension points, and district anchor (once districts exist).
- **`### Questline: "[Title]"`** — a reusable questline concept, including core premise, structure, themes, and possible endings.

A separate **`## Miscellaneous Faction Seeds`** section (entries not necessarily tied to a specific reassigned character) is also a legitimate part of this file's structure, each entry noting its original character seed if one exists.
