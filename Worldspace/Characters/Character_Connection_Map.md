## What Belongs Here (for reference)

Inner Tepenia's version of this file used a mix of:
- **Relationship diagrams** for significant multi-character/multi-faction connections (e.g., a triangle linking a narrator character, a technical partnership, and a faction reward tied to both).
- **Narrative-role write-ups** describing a recurring character function across multiple questlines.
- **Cross-faction thematic notes** (e.g., a shared mythology or in-world belief system referenced by more than one faction).
- **A "Deferred Design Issues" table** — open connective-tissue questions not yet resolved, with a priority level.

Each of these is a legitimate shape for a future entry here. None should be invented ahead of the characters and factions they'd actually connect.
