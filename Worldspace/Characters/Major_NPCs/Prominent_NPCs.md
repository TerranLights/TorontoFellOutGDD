# Prominent NPCs

**Status: empty — pending Toronto Fell Out's own character design.** Inner Tepenia's version of this file ("Characters & Companions") listed one recruitable companion per Zodiac district, each strongly tied to that district's culture and values, plus a design-notes section on how companions map to district identity.

Toronto Fell Out has **zero designed districts, factions, or companions** — this is the single most important constraint on this file. The one-companion-per-district structure Inner Tepenia used doesn't transfer directly, since it depends entirely on a district roster that doesn't exist yet. No districts, companions, or NPCs have been invented to fill this file.

This file will hold Toronto Fell Out's own roster of prominent (non-template) NPCs — including, but not limited to, recruitable companions — once character design begins.

## Format (for reference — no entries yet)

Each prominent NPC entry should include, at minimum:

- **Name / working ID**
- **Role / Archetype**
- **District or Location affiliation** *(TBD until Toronto Fell Out's own districts are designed)*
- **Companion Potential:** Yes / No / Conditional / Romance / Rivalry / etc. (see `Companion-System.md` for the dual-slot human + non-human model this maps into)
- **Key Traits** relevant to their mechanical role
- A short description of their personality and story function

## Design Notes (for reference)

Inner Tepenia's design notes for this file are still a reasonable target to aim for once Toronto Fell Out has its own cast:
- Companions should feel native to wherever they're from, once that "where" exists — a neighborhood, faction, or district's own culture and values, not a generic archetype dropped in.
- Each companion should have real mechanical synergy with the content they're tied to.
- Recruiting and building relationships with them should unlock character-specific storylines, unique perks, and (per `Companion-System.md`) romance content where applicable.
