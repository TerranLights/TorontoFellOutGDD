# Preliminary Faction Possibilities

**Status: not started.** Inner Tepenia's version of this file listed a set of specific, fully-realized factions (The Veilkeepers, The Lattice, Frost Ascetics, Siligel Purists, and others) built entirely around Inner Tepenia's own lore, Zodiac districts, and cast. None of that content is applicable to Toronto Fell Out, and — unlike some of the other files ported over from Inner Tepenia — there wasn't a reusable structural pattern in it distinct enough from a generic faction-writeup shape to be worth extracting on its own.

**Toronto Fell Out has zero designed factions.** This file is a placeholder marking that as an open task, not an attempt to sketch one.

## Where to Start

When faction design for Toronto Fell Out actually begins:

- **`Hometown-based_Faction_Possibilities.md`** (in this same folder) documents the intended starting technique — "Geography is Character," a method for deriving organic community/faction identity from a neighborhood or population's lived environmental and occupational history, illustrated at a meta level against real Toronto geography. Start there rather than from a blank page.
- Cross-reference `Reference/Main-Storyline-Candidates.md` for any faction implications already embedded in the four main-storyline candidate directions (e.g., a quarantine-enforcing authority, an awakened automated-defense system, a faction squatting on the tower's frequency) — some of Toronto Fell Out's eventual factions may need to grow out of those threads rather than being designed independently of them.
- Cross-reference `Reference/Open-Worldbuilding-Decisions.md` for bestiary/terminology decisions that could affect faction flavor (e.g., whether super mutants or other FNV-derived creature types exist in this setting).
